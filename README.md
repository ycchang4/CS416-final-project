# Climate Change Data Visualization

This project presents an interactive data visualization of climate change indicators, including temperature changes, CO2 emissions, and sea level rise. The project uses a martini glass narrative visualization approach.

## Project Overview

This web-based visualization project aims to provide insights into climate change through interactive data visualizations. The project includes multiple pages focusing on different aspects of climate change:

- **Home Page**: Introduction to the project and navigation to different visualizations
- **Temperature Changes**: Visualization of global temperature trends
- **CO2 Emissions**: Analysis of carbon dioxide emissions over time
- **Sea Level Rise**: Data visualization of rising sea levels
- **Conclusion**: Summary of findings and implications

## Features

- Interactive data visualizations using D3.js
- Martini glass narrative visualization structure
- Responsive design for different screen sizes
- Multiple visualization types (line charts, bar charts, etc.)
- Data-driven insights about climate change
